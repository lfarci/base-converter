# Base Converter

A live number-base converter for learning how the same whole number is written in different bases. Each row’s place-value equation shows how the radix power and digit produce every addend in the total, with separators for large contributions and totals. The Breakdown heading stays visible while its panel is shown; zero or empty values display a prompt until a value is entered. Expanded calculations reveal with a brief opening/closing motion, which is disabled when reduced motion is preferred. Use the bulk controls to expand every row or hide all breakdown content.

**[Open the app](https://lfarci.github.io/base-converter/)**

## Run locally

```sh
npm install
npm run dev
```
